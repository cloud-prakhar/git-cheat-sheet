# Recommended Learning Resources

Trusted tools, interactive tutorials, and practice sites for guided, hands-on learning.

## 🛠️ Tools & Utilities

| | Resource | Description |
|---|----------|-------------|
| 🖥️ | [GitLens (VS Code)](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens) | Supercharged Git integration inside VS Code |
| 🌳 | [Sourcetree](https://www.sourcetreeapp.com/) | Free visual Git client for macOS and Windows |
| 🔍 | [git-extras](https://github.com/tj/git-extras) | Extra commands (`git undo`, `git summary`, `git changelog`, …) |
| 🧹 | [BFG Repo-Cleaner](https://rtyley.github.io/bfg-repo-cleaner/) | Fast alternative to `git filter-branch` for removing secrets/large files |
| 🧼 | [git-filter-repo](https://github.com/newren/git-filter-repo) | The recommended history-rewriting tool |
| 🔒 | [gitleaks](https://github.com/gitleaks/gitleaks) | Scan for committed secrets |
| 🪝 | [pre-commit](https://pre-commit.com/) | Framework for managing Git pre-commit hooks |
| 📊 | [git-standup](https://github.com/kamranahmedse/git-standup) | Recall what you (or your team) committed last working day |
| 📦 | [Git LFS](https://git-lfs.com/) | Large File Storage for binaries |

## 🎮 Interactive Learning

| | Resource | Description |
|---|----------|-------------|
| 🌐 | [Learn Git Branching](https://learngitbranching.js.org/) | Visual, interactive branching tutorials in the browser |
| 🎯 | [Oh My Git!](https://ohmygit.org/) | Open-source game for learning Git visually |
| 🧩 | [Git Katas](https://github.com/eficode-academy/git-katas) | Hands-on exercises for deliberate practice |
| 📺 | [Git Immersion](https://gitimmersion.com/) | A guided tour through Git fundamentals |

## 📚 Books & Guides

| | Resource | Description |
|---|----------|-------------|
| 📗 | [Pro Git (free)](https://git-scm.com/book/en/v2) | The definitive Git book — basics to internals |
| 📘 | [Atlassian Git Tutorials](https://www.atlassian.com/git/tutorials) | Clear, example-driven guides for every topic |
| 📙 | [Think Like (a) Git](https://think-like-a-git.net/) | A graph-theory mental model for Git |
