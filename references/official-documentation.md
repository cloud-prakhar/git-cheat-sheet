## Built-In Help (Always Available, Even Offline)

| Command | What It Does |
|---------|--------------|
| `git help <command>` | Opens the full man page for a command |
| `git <command> -h` | Quick flag summary |
| `git help -g` | Lists the concept guides (e.g. `gitworkflows`, `gitglossary`) |
