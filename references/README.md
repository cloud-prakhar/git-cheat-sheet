## How to Use

- Use **official documentation** as the source of truth — especially the [Pro Git book](https://git-scm.com/book/en/v2), which is free and comprehensive.
- Use the recommended resources for guided, hands-on learning.

## A Note on Trust

All links here point to **official or well-established** sources. When in doubt, prefer the official docs and the built-in help over random blog posts.

> Tip: `git help <command>` and `git <command> -h` are the fastest, most reliable references — always available, even offline.
